# Using B.C. Design System in this project

This project uses the B.C. Government Design System.

## Design system reference

Skill repo: https://github.com/richfrem/claude-design-bc-gov-design-system

Before designing any UI, read:
- `SKILL.md` — instructions and core rules
- `README.md` — full brand guidelines

## Quick rules

- Font: BC Sans (woff2 files in `fonts/`) — mandatory for all BC gov interfaces
- Primary: `#013366` | Hover: `#1E5189` | Focus: `#2E5DD7`
- Text: `#2D2D2D` | Surface: `#FAFAF8` | Border: `#D8D8D8`
- Radius: `4px` | No gradients | No emoji | Sentence case copy
- Always include Indigenous acknowledgment in full-page footers

## Assets available in the skill repo

- `assets/bc-logo.png` — BC Government wordmark
